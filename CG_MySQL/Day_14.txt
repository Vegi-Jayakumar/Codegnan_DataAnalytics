mysql> /* Queries and Sub-Queries
   /*> Sub-Query is a query inside another query.
   /*> It is written inside paranthesis() and its result is used by the outer query.
   /*> It is also called as inner query, nested query, inner select
   /*> 
   /*> purpose of Sub-Query
   /*> 1. to breakdown complex problems into smaller queries.
   /*> 2. to use the result of one query as input to another.
   /*> 3. to avoid multiple steps (write in a single query instead of temp tables).
   /*> 
   /*> general syntax
   /*> select column_list from table where column operator(select column from table where condition);
   /*> 
   /*> types of Sub-Queries
   /*> 1. single row sub-query
   /*> 2. multi row sub-query
   /*> 3. nested sub-query
   /*> 4. corelated sub-query
   /*> 5. exists/not exists sub-query
   /*> 
   /*> single row sub-query: single row subqueries returns exactly one row and one column. They use comparision operators like =,>,<,<=,>=,!=
   /*> characteristics:
   /*> 	> returns only one value
   /*> 	> can use single-value comparision operators.
   /*> 	> if subquery returns no rows or multiple rows, it causes an error.
   /*> 
   /*> syntax: select columns from table where column operator (select column from table where condition);
   /*> 
   /*> multi row sub-query:
   /*> a. multi row sub-query in: it returns more than one row. the in operator is used when you want to compare a value with multiple values returned by the subquery
   /*> characteristics:
   /*> 	> returns multiple rows.
   /*> 	> use the in operator.
   /*> 	> checks whether a value exists in the list returned by the subquery.
   /*> 	> equivalent to multiple or condition.
   /*> 	> most commonly used for matching values.
   /*> 
   /*> suntax: select column from table where column in(select column from table where condition);
   /*> 
   /*> b. multi row subquery any/some: it returns multiple rows when using any or some. The condition is true if it matches atleast one value returned by the subquery.
   /*> characteristics:
   /*> 	> returns multiple values.
   /*> 	> any and some are interchangable.
   /*> 	> condition is true if any of the values satisfy the condition.
   /*> 	> often used with in, >any, <any, >=any ... etc
   /*> 
   /*> syntax: select column from table where column operator any/some(select column from table where condition);
   /*> 
   /*> c. multi row subquery all: The all operator means the condition must be true for all values returned by the subquery.
   /*> characteristics:
   /*> 	> conditions must be true for all values in the subquery result.
   /*> 	> often used with >all, <all, <=all, >= all
   /*> 	> >all means greater than maximum value
   /*> 	> <all means less than minimum value
   /*> 
   /*> syntax: select column from table where column operator all(select column from table where condition);
   /*> 
   /*> nested sub-query: They are subqueries within subqueries. they can be multiple levels deep and are executed from innermost to the outermost.
   /*> characteristics:
   /*> 	> multiple levels of nesting
   /*> 	> inner queries execute first.
   /*> 	> can combine different types of subqueries
   /*> 	> useful for complex conditions
   /*> 
   /*> syntax: select column_list from table where column = (select column from table where column = (select column from table where condition));
   /*> 
   /*> corelated sub-query: they are subqueries that reference columns from outer query. unlike regular subqueries that execute once. corelated subqueries execute once per each row processed by the outerquery
   /*> characteristics:
   /*> 	> reference column from outer query.
   /*> 	> executes multiple times(once per outer row).
   /*> 	> cannot be executed independently.
   /*> 	> often used with exists/not exists.
   /*> 	> generally slower than non-corelated subquerues.
   /*> 
   /*> syntax: select column from table1 outer_alias where condition(select column from table2 inner_alias where inner_alias.column = outer_alias.column);
   /*> 
   /*> exists/not exists sub-query: exists is used to test weather a subquery returns any rows. it returns TRUE if the subquery returns as least one row. False otherwise.
   /*> 				    not exists return TRUE if the subquery returns no rows.
   /*> characteristics:
   /*> 	> returns TRUE/FALSE(boolean result).
   /*> 	> more efficient than in for large datasets.
   /*> 	> often used with corelated subqueries.
   /*> 	> stops execution as soon as first match is found.
   /*> 	> select clauses in exists doesn't matter(often use select 1).
   /*> 
   /*> syntax: select columns from table1 where exists(select 1 from table2 where condition).
   /*> syntax: select columns from table1 where not exists(select 1 from table2 where condition).	*/
