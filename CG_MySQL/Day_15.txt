mysql> /* Views
   /*> A view is a virtual table created from the result of select query. It does'nt normally store the actual data separately instead it stores the SQL Query and whenever you access the view,
   /*> MySQL retrieves the data from the underlying tables.
   /*> 
   /*> Why do we need views?
   /*> 1. simplify complex queries.
   /*> 2. reuse query logic.
   /*> 3. data security.
   /*> 4. simplified reporting.
   /*> 
   /*> Advantages of views
   /*> 1. simplicity
   /*> 2. security
   /*> 3. reusability
   /*> 4. consistancy
   /*> 5. maintainability
   /*> 6. no extra storage cost
   /*> 
   /*> difference between table and view
   /*> - table physically stores data -- view is virtual table based on query
   /*> - can store records directly -- usually doesn't store separate records
   /*> - create using create table -- create using create view
   /*> - contains all the data -- can show selected rows/columns
   /*> -used for permanent data storage -- mainly used for abstract, security, and reusable queries.
   /*> 
   /*> syntax: create view view_name as select column_name from table_name where condition;
   /*> 
   /*> alter view: alter view view_name as select new_columns from new_tables where new_conditions;
   /*> 
   /*> drop view: drop view view_name;
   /*> */
