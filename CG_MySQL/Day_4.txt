mysql> /* Constraints: */
mysql> /* They are rules applied to a table columns in MYSQL to ensure that only valid and accurate data is stored in the database.
   /*> In simple words Constraints = rules that control the data entered into a table.
   /*> Why do we use constraints?
   /*> 1. maintain data integrity.
   /*> 2. Prevent invalid data entry.
   /*> 3. avoid duplicare records.
   /*> 4. ensure relationships between tables.
   /*> 5. Make the database reliable and consistent.*/
mysql> /* Integrity constraints;
   /*> 1. not null
   /*> 2. unique
   /*> 3. Primary key
   /*> 4. Composite key
   /*> 5. foreign key
   /*> 6. default
   /*> 7. check */
mysql> /* not null: It ensures that a column cannot contain null(empty) values. every row must have a value for that column.
   /*> not null = doesn't allow null values. */
mysql> /* unique key: it ensures that all values in a column are different. duplicate values are not allowed. */
mysql> /* primary key: it is a combination of unique key and not null */
mysql> /* Composite key: it is a table level constraint which is used to assign multiple primary key columns in a table.
   /*> The values in composite key constraints are treated as a set and does not allow duplicate values.
   /*> Note: if even one value in the set is unique then it is treated as a new set even if it has duplicate values compared to other sets. */
mysql> /* default: It automatically assigns a predefined value if no value is provided during insertion. */
mysql> /* check: It ensures that values satisfy a specified condition before insertion or update. */
mysql> /* foreign key: It creates a relation between two or more tables. It ensures that values in the child table must exist in the parent table.
   /*> the table where we assign foreign key is the child table and the tables to which it is linked to is the parent table. it is a tables level constraint. */
mysql> /* Referencial Actions */
mysql> /* Referential actions defines what happens to child table data when parent table data is updated or deleted.
   /*> commands: on delete cascade, on update cascade, on delete set null, on update set null */
